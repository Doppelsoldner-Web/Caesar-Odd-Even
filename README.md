# Odd/Even Cipher — Encoder & Decoder

An interactive web application built with HTML, CSS, and JavaScript for text encoding and decoding. The logic is based on applying the Caesar cipher independently to characters at odd and even positions within each word, interleaving the result into a single string without spaces.

---

## 🚀 Features

- **Independent Word Shifts:** Each word has its own isolated displacement keys for odd positions (1st, 3rd, 5th...) and even positions (2nd, 4th...).
- **Interleaving Matrix:** The final result is generated by merging the ciphered words character by character (zigzag style).
- **Decoder with Structural Reconstruction:** Reconstructs the original phrase using the ciphered text and the word lengths vector.
- **Large Key Space:** For a text of just two words, the system offers $456,976$ possible combinations ($26^4$).
- **Responsive Interface:** Developed in Vanilla JavaScript with no external libraries or framework dependencies.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic and accessible structuring of tabs and panels.
- **CSS3:** Styling using native variables, flexible layout, and support for reduced motion preferences.
- **JavaScript (ES6+):** DOM manipulation, positional shift algorithms, and clipboard handling.
